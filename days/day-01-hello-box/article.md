## GSAP 是什麼？解決什麼問題？

GSAP 全名是 **GreenSock Animation Platform**，簡單說就是一套「用 JavaScript 控制動畫」的函式庫。

雖然 CSS 本身就能做動畫惹（`transition`、`@keyframes`），但如果今天動畫變成**多步驟**，例如「A 先移動、等它動完 B 再淡入、然後 C 再放大」用純 CSS 就很麻煩ＸＤ，因為要動手去算每個東西的 `animation-delay`，只要中間想調一個時間點，後面全部要跟著重算，牽一髮動全身。

那 GSAP 的存在，就是來解決這種串接的麻煩，它能夠將一連串的動畫像排時間軸一樣排好，想插隊、想重疊、想調順序，改一行就好，不用重算一堆數字。如何串接後面會講到～今天的重點是認識什麼是 GSAP 就好。

## 在開始玩之前，怎麼安裝

最快的方式：用 **CDN**，一行 `<script>` 就能用，完全不需要 build 工具。把這行放進 HTML 的 `<head>` 裡：

```html
<script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.5/gsap.min.js"></script>
```

這樣頁面載入後就會有一個全域的 `gsap` 可以用了，灰常簡單 👍
但如果今天有使用 Vue / React 之類的框架，也可以改用 `npm i gsap` 安裝，都是**同一個 GSAP**，只是引入方式不同而已。

## 小試身手！先讓方塊動起來

先在頁面上放一個方塊：

```html
<div class="box"></div>
```

這是方塊的長相，一個 100px 的綠色正方形，帶著一點圓角。

```css
.box {
  width: 100px;
  height: 100px;
  background: #4ade80;
  border-radius: 8px;
}
```

然後，讓它動起來的 GSAP 只要這幾行，很好懂 😗

```js
gsap.to(".box", {
  x: 300,
  duration: 1,
});
```

打開頁面，方塊就會在 1 秒內從左邊滑到右邊，一起來拆解這行在做什麼。

<!-- 圖（建議用 GIF）：方塊在 1 秒內從左滑到右的動畫。靜態截圖看不出「動」，用 GIF 或短影片最能呈現，發文時在 iThome 上傳 -->

```js
gsap.to(要動誰, { 要動成什麼樣 });
```

- **`gsap.to(...)`**：`.to()` 的意思是「**從現在的樣子，動到你指定的樣子**」。方塊現在在左邊，我們叫它「動到」右邊。
- **第一個參數 `".box"`**：要動的目標，寫法就是 CSS 選擇器，跟你平常選元素一樣。
- **第二個參數 `{ ... }`**：這是動畫的「終點狀態」，你想讓它變成什麼樣，就寫在這個物件裡。
  - **`x: 300`**：往右移動 300px（`x` 對應的是 CSS 的水平位移）。
  - **`duration: 1`**：動畫花多久，單位是**秒**，所以是 1 秒。

看懂 `gsap.to(誰, { 動成什麼 })` 這個模型，就是今天的重點，後面所有動畫，幾乎都是從這個結構長出來的。（`{ }` 裡其實還能放很多屬性，像旋轉、縮放、換緩動手感等等。）
