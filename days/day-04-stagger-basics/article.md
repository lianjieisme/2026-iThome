## Stagger 是什麼？解決什麼問題？

先想像沒有 stagger 的話，假設你有 9 個方塊要依序進場，土法煉鋼的寫法大概會長這樣👇

```js
gsap.to("#box-1", { y: 0, opacity: 1, delay: 0 });
gsap.to("#box-2", { y: 0, opacity: 1, delay: 0.12 });
gsap.to("#box-3", { y: 0, opacity: 1, delay: 0.24 });
// ...一路手算到 box-9，改個間隔全部都要重寫 😵
```

Stagger 就是來解決這個的！它是 GSAP 動畫設定裡的一個屬性，意思是「這一群目標，每個之間自動錯開一點時間」。你只要選到一整群元素、寫一次動畫，它就會幫你把 delay 分配好。

```js
// 一次選 9 個 .box，stagger 會自動錯開
gsap.to(".box", {
  y: 0,
  opacity: 1,
  duration: 0.5,
  stagger: 0.12, // ← 今天的主角
});
```

一行取代上面那一長串，而且方塊 9 個變 20 個也不用改～今天只會先示範「一排」的 stagger，也就是控制**間隔多長**和**從哪個方向開始**這兩件事。

## 怎麼做

### 一、最簡單：數字型 stagger

`stagger` 先給一個數字，就是「每個元素之間間隔幾秒」。

```js
gsap.to(".box", { y: 0, opacity: 1, duration: 0.5, stagger: 0.12 });
```

這行的意思是：從第 1 個立刻開始，第 2 個晚 0.12 秒，第 3 個晚 0.24 秒...以此類推。就這樣，一排方塊由左到右依序進場。

> 🕳️ 小提醒：`stagger` 是放在動畫設定物件（第二個參數）裡的一個屬性，不是 `gsap.to()` 的另一個參數。很多人第一次會寫成 `gsap.to(".box", {...}, 0.12)`，要寫在{}裡面唷！

### 二、each vs amount：間隔怎麼算

若你想更精細控制時間，`stagger` 可以改成一個物件的寫法，裡面有兩種算間隔的方式，**擇一使用**：

```js
// 方式 A：each = 每個之間固定間隔 0.12 秒
gsap.to(".box", { /* ... */ stagger: { each: 0.12 } });

// 方式 B：amount = 整組從頭到尾總共花 0.8 秒，間隔自動攤分
gsap.to(".box", { /* ... */ stagger: { amount: 0.8 } });
```

差別在哪？

- **`each`**：間隔是固定的。元素越多，整組動畫會越久（9 個就是 0.12 × 8）。
- **`amount`**：總時間是固定的。不管幾個元素，整組就是在 0.8 秒內跑完，元素越多間隔越密。

### 三、from：從哪個方向開始跑

預設是從第一個元素開始（左到右）。加上 `from`，就能換起跑點：

```js
gsap.to(".box", {
  /* ... */
  stagger: { each: 0.12, from: "center" }, // 從中間往兩邊擴散
});
```

`from` 常用這幾個值：

- `"start"`：從第一個開始（預設）。
- `"center"`：從中間往兩邊。
- `"end"`：從最後一個倒著來。
- `"edges"`：從頭尾兩端往中間夾。
- `"random"`：隨機順序，亂中有序的感覺。

同樣一排方塊，光是換 `from`，進場的樣子就會完全不一樣。

## 小結

今天的重點只有一個：**stagger 讓「一排」元素自動錯開時間依序動**，再也不必手寫一堆 delay。

| 想控制的事 | 用什麼                     | 白話                     |
| ---------- | -------------------------- | ------------------------ |
| 間隔多長   | `stagger: 0.12`            | 每個之間差幾秒           |
| 固定間隔   | `stagger: { each: 0.12 }`  | 元素越多、整組越久       |
| 固定總長度 | `stagger: { amount: 0.8 }` | 總時間不變、間隔自動攤分 |
| 從哪開始   | `from: "center"` 等        | 換起跑方向，氣勢就不同   |

這些都是「一排」元素的玩法，也就是一維的排列。那如果元素不是排成一條線，而是排成一個**網格**呢？stagger 還能讓它從中心像水波一樣擴散出去，我們下篇見 👋
