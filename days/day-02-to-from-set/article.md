# Day 02：`.to` / `.from` / `.set` / `.fromTo` tween四兄弟

## 前言

哈囉又是我～歡迎回到「人要可愛，網頁也要動感迷人系列」的 Day2。
昨天我們用 `gsap.to(誰, { 動成什麼 })` 讓方塊從左滑到右，成功看到物件動起來了 ✨
但其實 `.to()` 只是 GSAP 動畫方法裡的「四兄弟」之一！今天就把另外三個一次認識完。

在開始之前，先給大家一個問句，它的概念會貫穿今天整篇：

> **「動畫的起點在哪、終點在哪？」**

你會發現，這四個方法其實是同一個問題的四種答案。

## `.to()`：從「現在」動到「指定」（昨天的範例，複習一下🖊️）

先幫昨天的主角複習一下。`.to()` 的意思是：**起點是「現在的樣子」，終點由你指定**。

```js
gsap.to(".box", {
  y: 120, // 往下移 120px
  duration: 1, // 花 1 秒
});
```

方塊本來在原地（起點＝現在），我們叫它「動到」下方 120px 的位置（終點＝指定）。
起點是誰？它現在的樣子。終點是誰？你 `{ }` 裡寫的那些。記住這個分法，下面三個就是把「起點/終點」換人當而已。

## `.from()`：起點和終點對調，適合做進場動畫

`.from()` 剛好跟 `.to()` **相反**：**終點是「現在的樣子」，起點則是由你指定**。

```js
gsap.from(".box", {
  y: -120, // 從上方 120px 的地方滑進
  opacity: 0, // 原本是透明的
  duration: 1,
});
```

翻成白話就是：「從（透明 + 上方）這個狀態，動回它現在該在的樣子」。
於是方塊會**從上面滑進來**，停在原本的位置，這也是進場動畫最常用的寫法 ✨
為什麼進場愛用它？因為你只要描述「它從哪來」，終點 GSAP 會自動用元素現在的樣子，灰常省事。

> 🕳️ 小提醒：`.from()` 在某些情況下，頁面剛載入會先「閃一下」最終狀態再跳回起點才開始動，常見於 JS 比畫面晚執行時（框架專案、`defer` / `module`、bundle 較大）。本篇這個小 demo 因為 GSAP 是同步載入、動畫在第一次繪製前就設定好了，所以看不太到。之後會分享遇到時怎麼解 🙌

## `.set()`：瞬間套用，不動畫

`.set()` 是四兄弟裡唯一**不會動**的：它把你指定的狀態**瞬間套上去**，沒有過程、沒有時間。

```js
gsap.set(".box", { y: 120 });
```

注意！它連 `duration` 都不用寫，因為根本不花時間 ⏰。
你可能會想說，那它存在的意義是什麼？它真正的用途是**在動畫開演前，先把元素擺到起始狀態**（例如先 `.set()` 成透明 + 偏移，之後再讓它 `.to()` 進場）。所以 `.set()` 常常是動畫的「前置作業」，之後串動畫時就會用到它。

## `.fromTo()`：起點、終點都自己指定

前面幾個方法，起點跟終點總有一邊是「現在的樣子」。`.fromTo()` 則是**兩邊都給你自己決定**，控制得最完整。

```js
gsap.fromTo(
  ".box",
  { y: -120, opacity: 0 }, // 起點：上方、透明
  { y: 120, opacity: 1, duration: 1 }, // 終點：下方、不透明
);
```

它吃**兩個**設定物件：第一個是起點、第二個是終點（`duration` 這種動畫設定會寫在終點那個物件裡）。
當「元素現在的樣子」剛好不是你要的起點時，`.fromTo()` 最好用，因為它不靠現況、兩端都交由你來自行決定。

## 四兄弟對照表

把今天的東西整理成下面這張表 📒

| 方法        | 起點 | 終點 | 會不會動    |
| ----------- | ---- | ---- | ----------- |
| `.set()`    | 現在 | 指定 | ❌ 瞬間套用 |
| `.to()`     | 現在 | 指定 | ✅          |
| `.from()`   | 指定 | 現在 | ✅          |
| `.fromTo()` | 指定 | 指定 | ✅          |

差別只在「起點/終點是**現在**或是**你自己指定**」，以及會不會動而已，很好懂。

## 小結

今天把 GSAP 的動畫四兄弟認識完，重點就是：**看「起點在哪、終點在哪」**。

- **`.to()`**：起點＝現在，終點＝指定（動）
- **`.from()`**：起點＝指定，終點＝現在（動）進場神器
- **`.set()`**：瞬間套用、不動畫，拿來設定初始狀態
- **`.fromTo()`**：起點、終點都自己指定，控制最完整
