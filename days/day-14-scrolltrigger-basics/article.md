# Day 14：ScrollTrigger 基礎，`trigger` / `start` / `end` / `toggleActions`

## 前言

歡迎回到「人要可愛，網頁也要動感迷人系列」的 Day14。
昨天我們讓動畫循環起來了，`repeat`、`yoyo`、`keyframes`，五個屬性都在調同一輪的某個面向。
頁面一載入就開始跑，或者滑鼠移上去就開始跑，總之跟你人在頁面的哪個位置完全無關。
但你逛過的那些好看的網站不是這樣。你捲到某一段，圖片才浮上來；你再往下捲，文字才一行一行出現。動畫在**等你**。
今天就來認識負責這件事的外掛，「ScrollTrigger 🎢」

## ScrollTrigger 其實不做動畫

這是今天最重要的一句話！

**ScrollTrigger 不會幫你做動畫，它只負責決定什麼時候叫動畫動起來。**
它比較像一座橋。一邊是使用者的捲動位置，另一邊是寫好的動畫，它負責把兩邊接起來。
動畫還是原本那個動畫，`gsap.to()` 怎麼寫就怎麼寫，ScrollTrigger 只是多了一個設定物件掛在旁邊。
還有一個更直接的證據：ScrollTrigger 可以完全不接動畫。

```js
// 不綁任何動畫，只是在捲到某個位置的時候做點事
ScrollTrigger.create({
  trigger: ".section",
  start: "top center",
  onEnter: () => console.log("捲到了"),
});
```

這段程式碼裡沒有任何 tween，但它是完全合法的 ScrollTrigger。它就只是一個捲動位置的偵測器，捲到了就叫你一聲。
一個連動畫都不需要的東西，當然不會是動畫 API ( • ̀ω•́ ) ✨

## 怎麼做

### 第一步：註冊外掛

ScrollTrigger 不在 GSAP 核心裡面，它是一個外掛，要另外載入註冊。

```html
<script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.15.0/gsap.min.js"></script>
<script src="https://cdnjs.cloudflare.com/ajax/libs/gsap/3.15.0/ScrollTrigger.min.js"></script>
```

```js
gsap.registerPlugin(ScrollTrigger);
```

這行寫一次就好，通常放在你的 JS 最上面。

> 🕳️ 小提醒：**忘了 `registerPlugin` 是新手最常卡的第一關。**

### 第二步：先來個最簡單能跑的例子

把 `scrollTrigger` 當成一個設定物件，塞進原本的動畫裡：

```js
gsap.to(".box", {
  x: 300,
  duration: 1,
  scrollTrigger: {
    trigger: ".box",
  },
});
```

這樣就已經是一個捲動觸發的動畫了。

`trigger` 指的是**要盯著誰**。你捲到這個元素附近的時候，動畫才會開始。
注意 `trigger` 跟被動畫的元素是兩件事，只是在這個例子裡剛好都是 `.box`。
實務上更常見的是盯著一整個區塊，然後動裡面的東西，如下方程式碼 ⬇️

```js
gsap.to(".card", {
  y: 0,
  opacity: 1,
  scrollTrigger: {
    trigger: ".section", // 像這樣，盯著某一整個區塊
  },
});
```

那「附近」到底是多近？現在還沒設定 `start` 和 `end`，所以用的是預設值。GSAP 的預設是 `start: "top bottom"`、`end: "bottom top"`，白話講就是：這個元素只要有一點點進到畫面，就算開始；整個離開畫面，就算結束。
這組預設很堪用，但你一定會想改。要改之前，我們先讓那些看不見的線現形。

### 第三步：打開 `markers`，把線畫出來

`start` 和 `end` 最痛苦的地方是它們**看不見**。你改了一個值，動畫的觸發時機好像變了又好像沒變，只能一直捲一直猜。
所以 GSAP 給了一個開發用的開關：

```js
gsap.to(".box", {
  x: 300,
  scrollTrigger: {
    trigger: ".box",
    markers: true, // 就這一行
  },
});
```

打開之後，畫面上會多出四條有顏色的線和標籤，兩兩一組：

| 線               | 貼在哪              | 意思                           |
| ---------------- | ------------------- | ------------------------------ |
| `start`          | 跟著 trigger 元素跑 | trigger 身上被拿來比對的那條線 |
| `end`            | 跟著 trigger 元素跑 | trigger 身上代表結束的那條線   |
| `scroller-start` | 釘在畫面上不動      | 視窗這邊用來比對開始的那條線   |
| `scroller-end`   | 釘在畫面上不動      | 視窗這邊用來比對結束的那條線   |

看懂這張表，你就能理解 ScrollTrigger 的運作方式了！
**兩條會跑的線（trigger 的）和兩條不動的線（視窗的），碰在一起的那一刻，事情就發生**。
你捲動的時候，畫面上的線是不動的，動的是 trigger 那兩條。當 `start` 那條往上跑到跟 `scroller-start` 對齊，動畫就開始。就這麼單純。

> 🕳️ 小提醒：**`markers` 一定要記得拿掉再上線唷！！！**
> 它會直接畫在你的頁面上，不是開發者工具裡面，使用者是看得到的。建議寫成 `markers: false` 留在那邊而不是整行刪掉，之後要 debug 再切回 `true` 就好。

### 第四步：`start` 和 `end` 的兩個字

現在來看今天真正的重頭戲。`start` 的值長這樣：

```js
start: "top center";
```

兩個字，中間一個空格。這兩個字是**兩個不同的座標**：

- **第一個字**講的是 **trigger 元素**身上的位置
- **第二個字**講的是**視窗**上的位置

所以 `"top center"` 讀作：當 trigger 元素的**頂端**，碰到視窗的**正中間**的時候。

> 🕳️ 小提醒：**這兩個字的順序不能反。**
> `"top center"` 和 `"center top"` 是兩件完全不同的事，前者是元素的頂端碰到畫面中央，後者是元素的中央碰到畫面頂端。寫反了不會報錯，只會讓動畫在莫名其妙的時機發生。記法是：**先定義自己，再定義畫面**。

搞懂這個之後，剩下的就是這兩個位置分別可以填什麼。

#### 寫法一：關鍵字

最好讀的一種，`top`、`center`、`bottom` 三選一。

```js
scrollTrigger: {
  trigger: ".box",
  start: "top bottom",   // 元素頂端碰到畫面底部（元素剛冒出來就開始）
  end: "bottom top",     // 元素底部碰到畫面頂端（元素完全離開才結束）
}
```

這組其實就是預設值。再看兩個常用的：

```js
start: "top center"; // 元素頂端捲到畫面正中間才開始，比預設晚很多
start: "center center"; // 元素正中間對到畫面正中間，元素置中的那一刻
```

我自己最常用的是 `"top center"` 附近的值。預設的 `"top bottom"` 太早了，元素才露出一咪咪而已，動畫就播完了ＸＤ

#### 寫法二：百分比

關鍵字其實就是百分比的簡寫，`top` 是 `0%`、`center` 是 `50%`、`bottom` 是 `100%`。所以你可以直接填一個數字：

```js
start: "top 80%"; // 元素頂端碰到畫面 80% 高的位置
```

`80%` 是從畫面**頂端**往下算的 80%，也就是靠近底部但還沒到底的地方。效果是元素快要進到畫面時就開始播，使用者捲下來剛好看到它動完，很自然。

兩個位置都可以用百分比，混搭也可以：

```js
start: "25% 75%"; // 元素 25% 高的地方，碰到畫面 75% 高的地方
```

#### 寫法三：`+=` 相對值

有時候你要的不是某個整齊的位置，而是「再往下一點點」。這時候用 `+=`：

```js
start: "top top+=100px"; // 元素頂端碰到「畫面頂端再往下 100px」的位置
```

`end` 這邊還有一個更好用的用法，直接寫相對於 `start` 的距離：

```js
scrollTrigger: {
  trigger: ".box",
  start: "top center",
  end: "+=300",   // 從 start 之後再捲 300px 就結束
}
```

當 `end` 只寫 `+=` 而沒有前面那兩個字的時候，它算的是**從 start 開始的捲動距離**。這個寫法在你想精準控制一段區間有多長的時候特別方便，之後講 pin 和 scrub 的時候會一直看到它。

#### 寫法四：函式（先知道有這回事就好）

`start` 和 `end` 也可以塞一個函式進去，回傳字串或數字：

```js
scrollTrigger: {
  trigger: ".box",
  start: () => "top " + (window.innerHeight * 0.6),
}
```

今天先不展開，因為它存在的理由跟一個我們還沒講的問題有關：**版面高度會變**。圖片載入、字型載入、手機轉向，這些都會讓你當初算好的位置整個失準。函式寫法就是為了應付這件事而生的，之後遇到那個問題的時候再一起看會比較有感。
現在你只要知道：這個位置除了字串，也可以放函式 ✍️

### 第五步：`toggleActions`，四個位置四個時機

最後一個設定。前面我們一直在講「碰到就開始」，但開始之後呢？捲過頭了呢？捲回來呢？

`toggleActions` 就是在回答這些。它的值是**四個動詞，用空格隔開**：

```js
toggleActions: "play none none reverse";
```

四個位置是固定順序，對應四個時機⌚️

| 位置    | 時機          | 什麼時候發生                |
| ------- | ------------- | --------------------------- |
| 第 1 個 | `onEnter`     | 往下捲，進入 start          |
| 第 2 個 | `onLeave`     | 往下捲，越過 end            |
| 第 3 個 | `onEnterBack` | 往回捲，從 end 那頭再進來   |
| 第 4 個 | `onLeaveBack` | 往回捲，從 start 那頭退出去 |

順序記法是：**先兩個往下，再兩個往上**。

每個位置可以填的動詞有這些，全部都是 Day11 學過的播放器操作：

| 動詞       | 意思               |
| ---------- | ------------------ |
| `play`     | 從現在的位置往下播 |
| `pause`    | 停在原地           |
| `resume`   | 從暫停的地方繼續   |
| `restart`  | 回到頭重播         |
| `reverse`  | 倒著播             |
| `complete` | 直接跳到結尾       |
| `reset`    | 直接跳回開頭       |
| `none`     | 什麼都不做         |

看到這裡你應該有感覺了：ScrollTrigger 真的沒有發明新東西，它就是幫你在四個時機呼叫這些你早就會的動詞。

以下三組是最常用到的組合。

**第一組：`"play none none none"`**

```js
toggleActions: "play none none none"; // 這也是不寫時的預設值
```

進場播一次，之後怎麼捲都不管它。這是最常用的一組，適合那種內容浮現的效果，播過就算了，使用者上下捲不會一直看到它重播。

**第二組：`"play none none reverse"`**

```js
toggleActions: "play none none reverse";
```

進場播，往回捲出去的時候倒回來。差別是使用者來回捲會看到動畫一來一往，比較有互動感。缺點是捲快一點會有點躁（？）。

**第三組：`"restart pause resume reverse"`**

四個位置全部用上，官方文件很愛拿這組當範例。拆開來讀就是：往下進場從頭重播、越過 end 就暫停、往回捲回來時繼續播、退出 start 就倒轉。
你不太會真的在專案裡用這組，但它很適合拿來理解四個位置各自在幹嘛，demo 裡面有放，可以切換感受一下～

## 小結

四個設定各自負責的事情：

| 想決定什麼       | 用哪個          | 不寫的話                            |
| ---------------- | --------------- | ----------------------------------- |
| 要盯著哪個元素   | `trigger`       | 沒有預設，一定要給                  |
| 什麼時候算開始   | `start`         | `"top bottom"`，元素一冒頭就開始    |
| 什麼時候算結束   | `end`           | `"bottom top"`，元素完全離開才結束  |
| 四個時機各做什麼 | `toggleActions` | `"play none none none"`，進場播一次 |
| 把線畫出來看     | `markers`       | `false`，什麼都看不到               |

最容易踩的三個：忘了 `registerPlugin` 會整個不動、`start` 那兩個字的順序反了不會報錯、`markers` 忘記拿掉就上線。

到目前為止，捲動對動畫來說還只是一個開關，碰到線就播、碰到線就停。但如果動畫的**進度**可以完全跟著你的捲動走呢？你往下捲一點它就前進一點，往回捲它就倒退，手指停下來它就停在那格。那才是那些讓人有點驚豔的網站在做的事，我們下篇見 👋
