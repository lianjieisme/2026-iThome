## 什麼是一輪？

循環動畫講白了就是同一段動畫重複播。那我們就需要一個詞，來稱呼重複播的其中一次。

GSAP 官方文件裡混用了 iteration、repeat、cycle 三個字在講同一件事，這系列之後統一叫它**一輪**。方塊從左跑到右，這樣叫一輪；跑完再跑一次，那是第二輪。

有了這個詞之後，今天的五個屬性就變得超好記：

| 想調什麼         | 用哪個          |
| ---------------- | --------------- |
| 一輪要播幾次     | `repeat`        |
| 一輪跑完倒著回來 | `yoyo`          |
| 兩輪之間喘口氣   | `repeatDelay`   |
| 一輪裡面跑好幾段 | `keyframes`     |
| 每一輪都不一樣   | `repeatRefresh` |

一個一個來看 ( • ̀ω•́ )！

## `repeat`：一輪要播幾次

最基本的一個，加上去就會重複：

```js
gsap.to(".box", {
  x: 300,
  duration: 1,
  repeat: 2,
});
```

想無限循環的話，填 `-1`：

```js
gsap.to(".box", {
  rotation: 360,
  duration: 1,
  ease: "none", // 無限旋轉記得用 none，不然每輪都會加減速，看起來會一頓一頓的
  repeat: -1,
});
```

> 🕳️ 小提醒：**`repeat: 2` 是播三次，不是兩次。**
> 這個數字的意思是播完之後**再重複**幾次，所以實際播放次數是 `repeat + 1`。想播 3 次就要寫 `repeat: 2`，想播 5 次就寫 `repeat: 4`。

## `yoyo`：跑完要不要倒著回來

`yoyo: true` 的意思是，每跑完一輪就反過來播回去，像溜溜球一樣。

```js
gsap.to(".box", {
  x: 300,
  duration: 1,
  repeat: -1,
  yoyo: true, // 跑到右邊之後，倒著滑回左邊，再往右
});
```

沒開 `yoyo` 的話，方塊跑到右邊會**瞬間閃回**起點再跑一次，中間那一下很突兀。開了之後就變成平順的來回。

`yoyo` 要搭 `repeat` 才有意義喔，光寫 `yoyo: true` 而沒有 `repeat` 是不會有任何效果的～

## `repeatDelay`：兩輪之間喘口氣

預設情況下，一輪播完會**立刻**接著下一輪。如果想讓它停一下再繼續，就用 `repeatDelay`：

```js
gsap.to(".box", {
  x: 300,
  duration: 1,
  repeat: -1,
  repeatDelay: 0.5, // 每輪結束後停 0.5 秒再開始下一輪
});
```

注意 `repeatDelay` 跟 `delay` **不一樣**：`delay` 只影響第一次開始前要等多久，之後就沒它的事了；`repeatDelay` 管的是每一輪之間的間隔。

## `keyframes`：一輪裡面跑好幾段

前面三個都是在調輪與輪之間的事，`keyframes` 是往裡面看：**一輪裡面，可不可以有好幾段動作？**

可以！就是把每一段當成一個小小的 `.to()` 排成陣列：

```js
gsap.to(".box", {
  keyframes: [
    { x: 300, duration: 0.55 }, // 第一段：往右移
    { y: -46, duration: 0.25 }, // 第二段：往上跳
    { y: 0, rotation: 360, duration: 0.4 }, // 第三段：落下並轉一圈
  ],
  repeat: -1,
});
```

這些段落會自動**前後接起來**，不用自己算 delay，整組的總長度就是每段 duration 加起來。想讓段落之間留空隙，可以給某一段一個 `delay`；給負的 `delay` 則會讓它跟前一段重疊。

另外它還有一種寫法，長得跟 CSS 的 `@keyframes` 幾乎一樣，用百分比標位置：

```js
gsap.to(".box", {
  keyframes: {
    "0%": { x: 0, y: 0 },
    "75%": { x: 300, y: -46, ease: "sine.out" },
    "100%": { x: 300, y: 0 },
  },
  duration: 2, // 百分比寫法要在外面給總 duration
  repeat: -1,
});
```

兩種寫法挑順手的用就好。我自己偏好上面那種陣列式，因為每一段自己帶 duration，要調某一段的長度不用回頭重算百分比。

> 🕳️ 小提醒：官方文件寫明 `keyframes` **只能用在 `.to()` 裡面**，所以別想把它塞進 `.from()` 或 `.fromTo()`。另外如果想控制 ease，`ease` 是管整組 keyframes 的節奏，`easeEach` 才是管每一段之間的。

## `repeatRefresh`：每一輪都不一樣

這個我覺得是今天最值得知道的！先看一段直覺上應該會每輪跳到不同位置的程式碼：

```js
gsap.to(".box", {
  x: "random(120, 380)", // 隨機一個位置
  duration: 1,
  repeat: -1,
});
```

實際跑起來，方塊只會在**同一個位置**來回，每一輪都一樣。

因為 `random()` 是在**建立這條 tween 的當下**就抽好一個數字記起來了，之後每一輪都是重播同一組已經記好的值，不會重抽。

想要每輪都重抽，要多加一個屬性：

```js
gsap.to(".box", {
  x: "random(120, 380)",
  duration: 1,
  repeat: -1,
  repeatRefresh: true, // ← 差在這一行
});
```

`repeatRefresh: true` 會讓 GSAP 在每一輪結束時，重新去計算一次那些動態的值，包含 `random()`、相對值（像 `"+=100"`）、還有用 function 回傳的值。加了它之後，方塊才會真的每輪跳到不同地方。

> 🕳️ 小提醒：官方文件特別註明，重抽的時機是**每一輪完整循環**，`yoyo` 的回程不算一輪。所以 `yoyo: true` 加 `repeatRefresh: true` 的時候，去程跟回程用的是同一組值，這是對的行為不是 bug。

## 順便認識一下 `gsap.utils`

上面那個 `random()`，其實是來自 GSAP 內建的一組小工具 `gsap.utils`。既然遇到了就順手把常用的幾個認識一下，之後很多地方都會用到。

**`random(最小, 最大)`**，剛剛用過的，也可以給第三個參數讓它抓整數倍，或直接丟一個陣列讓它隨機挑一個：

```js
gsap.utils.random(0, 100); // 0 到 100 之間的隨機數
gsap.utils.random(0, 100, 5); // 一樣但只會抽 5 的倍數
gsap.utils.random(["red", "green", "blue"]); // 從陣列裡隨機挑一個
```

**`clamp(最小, 最大, 值)`**，把一個數字夾在範圍內，超出去就取邊界值：

```js
gsap.utils.clamp(0, 100, -12); // 0，因為 -12 太小了，夾回下限
```

還記得 Day 8 做磁吸效果的時候，我在算滑鼠位置那邊偷用了 `clamp` 但沒解釋嗎，就是這個！當時是為了讓滑鼠貼著邊緣時，方塊不會被裁掉一半 🖊️

**`mapRange(原本最小, 原本最大, 對應到最小, 對應到最大, 值)`**，把一個範圍的數字換算到另一個範圍：

```js
gsap.utils.mapRange(-10, 10, 0, 100, 5); // 75
```

聽起來抽象，但它超實用。例如把滑鼠在畫面上的位置（0 到 螢幕寬）換算成旋轉角度（-20 到 20 度），一行就解決，不用自己推公式。

**`toArray()`**，把各種東西轉成真正的陣列，包含 CSS selector：

```js
gsap.utils.toArray(".card"); // [div.card, div.card, div.card]
```

用 `querySelectorAll` 拿到的是 NodeList，不能直接用 `.map()`，`toArray` 幫你省掉轉換那一步。

**`wrap()`**，數字超過範圍就繞回頭，這個之後做無縫跑馬燈會用到：

```js
gsap.utils.wrap(5, 10, 12); // 7，因為 12 超過上限 10 兩格，就從 5 往前數兩格
gsap.utils.wrap(["red", "green", "yellow"], 5); // "yellow"，索引超過陣列長度就繞回去
```

繞回頭這個概念，正好就是無限循環的跑馬燈需要的東西，之後聊到那個效果時我們會回來找它 👀

## 小結

今天的重點只有一個字：**輪**。你不用背五個屬性，只要記得它們調的都是同一件事。

| 想調什麼         | 用哪個          | 不寫的話            |
| ---------------- | --------------- | ------------------- |
| 一輪要播幾次     | `repeat`        | `0`，只播一輪       |
| 一輪跑完倒著回來 | `yoyo`          | `false`，直接閃回   |
| 兩輪之間喘口氣   | `repeatDelay`   | `0`，立刻接下一輪   |
| 一輪裡面跑好幾段 | `keyframes`     | 沒有，一輪就一段    |
| 每一輪都不一樣   | `repeatRefresh` | `false`，值只抽一次 |

最容易踩的兩個：`repeat: 2` 是**播三次**，還有 `random()` 沒配 `repeatRefresh` 是**不會重抽**的。這兩個都不會報錯，所以只能靠記得 ＸＤ
