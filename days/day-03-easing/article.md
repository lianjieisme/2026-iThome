# Day 03：Easing 視覺化比較（動畫的「手感」）

## 前言

哈囉大家～歡迎回到「人要可愛，網頁也要動感迷人系列」的 Day3。
昨天我們把動畫四兄弟 `.to / .from / .set / .fromTo` 認識完了，今天換介紹動畫的靈魂 **ease**，明明同樣的位移、同樣的時間，換不同的 ease 手感卻可以完全不同！

## Easing 是什麼？解決什麼問題？

Easing 是一個從時間 t (0→1) 對應到進度 p (0→1) 的函式。線性（linear）代表等速，一顆球彈起會先快後慢，一個彈簧會來回震盪，ease 就是描述 **這種變化的節奏**。
動畫在起點到終點之間，速度是怎麼分配的？沒有 easing 的動畫看起來會很假；加了合適的 easing，可以讓畫面更自然、更貼近日常我們所理解的樣子～

那今天會先認識最常用的幾種，用「同時起跑」的方式，一眼比出差異👀。

## 怎麼做

寫法很單純：在動畫設定物件裡多加一個 `ease` 屬性就好，其他都不用改。

```js
gsap.to(".box", {
  x: 320,
  duration: 1.5,
  ease: "power2.out", // ← 就多這一行
});
```

在開始比較前，可以簡單先分成兩大類：

- **數學型（速度曲線）**：單調地從起點跑到終點、不會超出，差別只在「加速 / 減速的節奏與強度」。例如 `power`、`sine`、`expo`。
- **效果型（模擬物理）**：不是純速度曲線，會**衝過頭**或**反覆震盪**，模擬現實世界的物理感。例如 `back`、`elastic`、`bounce`。

今天的 demo 讓每顆方塊都**跑一樣的距離、花一樣的時間**，唯一不同的就是 `ease`，差異來自 easing 本身，我們分兩區來看！

### 數學型：調的是「速度感」

<!-- 這邊插入這四種的GIF 圖 -->

```js
gsap.to("#box-none", { x: 320, duration: 1.5, ease: "none" });
gsap.to("#box-power2", { x: 320, duration: 1.5, ease: "power2.out" });
gsap.to("#box-sine", { x: 320, duration: 1.5, ease: "sine.out" });
gsap.to("#box-expo", { x: 320, duration: 1.5, ease: "expo.out" });
```

- **`none`（linear）**：全程等速，沒有加速也沒有減速，當基準線用。
- **`sine.out`**：最柔和、最不明顯的減速，適合呼吸感、微互動。
- **`power2.out`**：先快後慢、收尾滑順，是 GSAP 的**預設值**，最百搭。
- **`expo.out`**：起步比較浮誇！瞬間衝出去再慢慢收，戲劇性最強。

但它們最後都會乖乖停在終點線，只是衝出去的猛度不同，這就是數學型的特色。

> 🕳️ 補充：每個 ease 後面都有 `.out`？這是 ease 的「方向」。`.in` 是「從慢到快」、`.out` 是「從快到慢」、`.inOut` 則是「頭尾慢、中間快」。同一個家族換方向手感就不同，這裡先統一用 `.out`（進場、移動最常用）。

### 效果型：模擬真實物理

<!-- 這邊插入這三種的GIF 圖 -->

```js
gsap.to("#box-back", { x: 320, duration: 1.5, ease: "back.out(1.7)" });
gsap.to("#box-elastic", { x: 320, duration: 1.5, ease: "elastic.out(1, 0.3)" });
gsap.to("#box-bounce", { x: 320, duration: 1.5, ease: "bounce.out" });
```

- **`back.out`**：衝過終點一點點再拉回來，帶一點俏皮的回彈，適合按鈕、彈窗。
- **`elastic.out`**：到終點後像彈簧一樣來回抖幾下才停，效果最誇張、最吸睛。後面的 `(1, 0.3)` 是它的兩個參數：**幅度**（衝多遠）和**週期**（抖多密），這裡是預設值；想更浮誇可以調成 `(2, 0.1)`。
- **`bounce.out`**：像球落地一樣，到終點會彈跳幾下，很有重量感。

跟數學型最大的差別：它們會**衝過終點線再回來**（或彈跳），而不是乖乖停住，這就是「模擬物理」的手感。

當然 ease 不只今天這幾種，甚至能自己畫曲線調出獨一無二的手感。想看完整清單、或自己動手拉曲線即時預覽，可以玩玩 GSAP 官方的 [Ease Visualizer](https://gsap.com/docs/v3/Eases/)，每種 ease 都能即時看到手感 ✨

## 小結

今天的重點只有一個：**easing 決定動畫從 A 到 B 的「手感」**，同樣的距離與時間，換個 ease 感覺就完全不同。而且可以先分兩大類記：

**數學型（速度曲線）**，單調跑到終點、差別在速度感：

| ease                | 特性                     | 適合場景          |
| ------------------- | ------------------------ | ----------------- |
| `power1`            | 最柔和，接近 CSS 的 ease | UI 微互動、hover  |
| `power2`            | 中等強度（**預設值**）   | 大部分位移動畫    |
| `power3` / `power4` | 加速很猛                 | 強調感、快速登場  |
| `sine`              | 最平滑、最不明顯         | 呼吸感、loop 動畫 |
| `expo`              | 起步 / 收尾非常快        | 戲劇性的進場      |
| `circ`              | 類似圓弧軌跡             | 少用、手感獨特    |

**效果型（模擬物理）**，會超出目標或反覆震盪：

| ease       | 特性                    | 適合場景        |
| ---------- | ----------------------- | --------------- |
| `back`     | 衝過頭再回彈            | 按鈕、彈窗      |
| `elastic`  | 像彈簧來回震盪          | 想吸睛的重點    |
| `bounce`   | 像球落地反彈            | 有重量感的物件  |
| `steps(n)` | 分 n 段跳動、無平滑過渡 | 逐格 / 像素動畫 |

挑 ease 沒有標準答案，多試幾個、憑感覺選最順眼的就對了 💯
