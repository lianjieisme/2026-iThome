# Day 05：Stagger grid 網格波浪（讓方塊從中心擴散）

## 前言

嗨嗨大家好！歡迎回到「人要可愛，網頁也要動感迷人系列」的 Day5。
昨天介紹基礎版的 **stagger**，讓「一排」方塊錯開時間依序進場。今天要來分享怎麼把方塊排成一個 **8×8 的網格**，讓進場順序不再是一條線，而是可以像漣漪一樣，從中心一圈一圈擴散出去 🌊

## grid 是什麼？解決什麼問題？

昨天的 `from: "center"` 在一排裡是從中間往左右兩邊，但如果今天方塊排成一個正方形網格，「中心」應該是**正中央那一點**，往上下左右四面八方擴散。

但 GSAP 預設不知道方塊是排成幾列幾欄的，它只看到 DOM 裡「第 1 個、第 2 個...第 64 個」這樣一條線，所以直接下 `from: "center"`，它只會抓「第 32 個」當中間，擴散方向還是錯的。

這時候主角 `grid` 就登場了。你只要告訴它「這是 8 列 8 欄」：

```js
stagger: {
  grid: [8, 8], // ← 8 列、8 欄
  from: "center",
}
```

GSAP 就會把那條一維的序號，重新理解成 8×8 的表格，改用「每一格到起點的距離」來排先後順序。距離近的先動、遠的後動。

## 怎麼做

### 一、告訴 GSAP 你的網格長怎樣

`grid` 接一個 `[列數, 欄數]` 的陣列。我們畫面上是 8×8，所以寫 `[8, 8]`：

```js
gsap.to(".cell", {
  scale: 1,
  opacity: 1,
  duration: 0.4,
  ease: "power2.out",
  stagger: {
    grid: [8, 8],
    from: "center",
    amount: 0.9, // 整組總共鋪開 0.9 秒（昨天學過的 amount）
  },
});
```

`amount` 是昨天講過的「總時間攤分」，因為 64 格不算少，用 `amount` 讓它整組在 0.9 秒內跑完，才不會拖太久。

### 二、換 from，水波的起點就變了

`grid` 排好之後，`from` 一樣可以換起點，但現在它是在**二維**上算距離：

- `"center"`：從正中央往四周擴散（招牌水波）。
- `"edges"`：從四個邊往中間收。
- `"start"`：從左上角那一格斜著掃過去。
- `"random"`：隨機亂數，像下雨。

同一個網格，光是換 `from`，擴散的形狀就能完全不同，是不是超酷滴 σ(`∀´)σ

### 三、axis：只想沿一個方向掃

前面的水波之所以是「同心圓」，是因為 `grid` 預設會同時看 x 和 y 兩個方向的距離。若你不想要圓形擴散，只想讓它整欄整欄或整列整列地掃過去，就加一個 `axis`：

```js
stagger: {
  grid: [8, 8],
  from: "center",
  axis: "x", // 只看水平距離
}
```

- `axis: "x"`：只算左右距離，同一欄的方塊同時動，變成**一欄一欄**左右掃。
- `axis: "y"`：只算上下距離，同一列的方塊同時動，變成**一列一列**上下掃。
- 不寫 `axis`：x、y 一起算，就是預設的同心圓水波。

> 🕳️ 小提醒：`axis` 要有 `grid` 才有意義（它是在二維上挑一個方向）。另外 `from: "random"` 是純亂數排序，會直接蓋過距離計算，所以它配 `axis` 是看不出差別的唷 ⚠️

### 四、grid 還有兩種進階寫法

```js
// 1. from 除了關鍵字，也能給 [x, y] 小數座標（0~1 的進度）
gsap.to(".cell", { /* ... */ stagger: { grid: [8, 8], from: [1, 0] } });
// [1, 0] = 右上角、[0.5, 0.5] = 正中央

// 2. grid: "auto" 讓 GSAP 依實際渲染位置自動算列欄，RWD 版面很好用
gsap.to(".cell", { /* ... */ stagger: { grid: "auto", from: "center" } });
```

> 🕳️ 小提醒：`from` 的座標是 `[x, y]`（先欄後列），而且值是 `0~1` 的比例、不是「第幾格」的整數索引，這兩個很容易搞混。

## 小結

今天的重點：**`grid: [rows, cols]` 把 stagger 的排序從一維的一條線，變成二維的一張表**，`from` 就能做出從中心擴散的水波 💧

| 想做的事     | 用什麼              | 白話                      |
| ------------ | ------------------- | ------------------------- |
| 告訴它是網格 | `grid: [8, 8]`      | 8 列 8 欄，改用距離排順序 |
| 中心水波     | `from: "center"`    | 從正中央往四面八方擴散    |
| 只沿單一軸掃 | `axis: "x"` / `"y"` | 一整列一整列地波過去      |
